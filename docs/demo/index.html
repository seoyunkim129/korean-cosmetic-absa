별점 하나로는 안 보이는 것 — 리뷰를 속성별 감정으로 나눠 읽기

리뷰 문장에서 보습력·자극성·가격 같은 속성 21개를 찾고, 속성마다 긍정·부정·중립을 나눴습니다. "결은 좋아졌는데 따끔해요" 같은 리뷰가 한 점수로 뭉개지지 않고, 내가 중시하는 속성으로 제품을 비교할 수 있습니다.

평균이 가린 불만

언급 10건 이상인 속성 중 모델이 부정으로 분류한 비율이 높은 곳. 같은 제품의 다른 속성은 대부분 긍정이라 리뷰 전체 톤에 묻히기 쉽습니다. 누르면 아래에서 자세히 봅니다.

    추천 순위

    고른 속성이 10건 이상 언급된 제품만 순위에 넣습니다 (언급 2건에 긍정 100%인 제품이 1위가 되는 걸 막기 위해). 행을 누르면 그 제품을 위에서 봅니다.

    어떻게 계산했나

    코드와 실험 기록은 GitHub 저장소에 있습니다.

    ① 속성 분류기

    KLUE-RoBERTa를 AI Hub 화장품 리뷰 12,000건으로 파인튜닝한 멀티라벨 분류기. 리뷰 하나에서 21개 속성을 동시에 찾고, 확률 0.6을 넘는 것만 씁니다 (속성을 놓치면 감정 분류로 넘어가지도 못해 Recall을 우선).

    ② 감정 분류기

    [CLS] 리뷰 [SEP] 속성 [SEP] 문장쌍을 넣어 "이 리뷰에서 이 속성에 대한 감정"을 분류합니다. AI Hub 테스트셋 Macro F1 0.892.

    ③ 지수

    • 기본 지수 — 속성별 긍정 비율을, 그 제품 리뷰에서 실제로 언급된 비율로 가중 평균 (고정 가중치 대신 제품마다 관심사가 다른 걸 반영)
    • 개인화 지수 — 고른 속성 긍정 비율 × 0.5 + 나머지 속성 × 0.5

    이 숫자가 말하지 않는 것

    • 제품당 리뷰 약 50건이라 속성별 언급은 5~30건 수준 — 비교용 참고 지표입니다
    • 만족한 사람이 리뷰를 더 써서 전반적으로 긍정 비율이 높습니다
